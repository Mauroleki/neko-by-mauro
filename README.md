# NekoCat By Mauro 2.0.5

[Descargar NekoCat.exe 2.0.5](https://github.com/Mauroleki/neko-by-mauro/releases/tag/v2.0.5). La aplicación incluye las 54 mascotas y recursos integrados.

La 2.0.4 remapea las 38 hojas de sprites: dos poses de espalda al subir, dos laterales para cada lado y poses frontales al bajar, conservando reposo y descanso.

Las instalaciones anteriores a 2.0.4 pueden requerir esta descarga manual porque el actualizador antiguo buscaba `Oneko.exe`. Desde 2.0.4, el actualizador busca `NekoCat.exe`.

Instrucciones y créditos están en `LEEME.txt` y `CREDITOS.txt`. El código fuente está en `Codigo`, los sprites en `Recursos` y el actualizador en `Sistema`.

La version 2.0.5 elimina las funciones de accesorios, objetos del escritorio y sorpresas aleatorias.
